# EVAIX Core Glossary

**The Kernel**
The core watcher daemon that continuously monitors the file system, parsing Markdown files to extract and execute embedded instructions.

**The Courier**
The local routing system responsible for directing tasks and passing context between different agents in the Minimum Viable Team.

**Entangled**
The concept of embedding executable code (`>CMD:` or ```typescript blocks) directly within human-readable Markdown prose. Agents communicate and execute operations through Entangled Markdown.

**The Padded Cell**
The sandboxed execution environment where potentially unsafe or untested code generated by agents is run to prevent system-wide instability or damage.

**Arbitrage**
The dynamic system for routing tasks to different language models based on their performance, cost, and reliability for the specific type of task requested.
